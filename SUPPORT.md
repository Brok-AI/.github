# Support

Thanks for using Brok-AI projects.

## Where to Get Help

- **Usage questions:** Open a GitHub Discussion in the relevant repository if Discussions are enabled.
- **Bug reports:** Use the repository's issue tracker and bug report template.
- **Feature ideas:** Open a feature request or start a discussion.
- **Installation and compatibility:** Include the project version, operating system, hardware, and relevant runtime details.
- **Security concerns:** Follow the private reporting instructions in `SECURITY.md`. Do not post vulnerabilities publicly.

## Before Asking

Please check:

1. The repository README and documentation.
2. Existing issues and discussions.
3. Release notes and known limitations.
4. Whether your question is specific to a particular version or platform.

## What to Include

To help maintainers understand your question, provide:

- The project and version you are using
- Your operating system and relevant environment details
- What you were trying to do
- What happened and what you expected
- A minimal reproduction or relevant error output, if applicable

Remove passwords, tokens, API keys, personal information, and other secrets before posting.

## Response Expectations

Brok-AI projects are maintained on an open-source basis. Support is provided on a best-effort basis, and response times may vary. Please keep requests respectful and focused.

Thank you for being part of the Brok-AI community.
