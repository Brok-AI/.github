# Brok-AI

### Building intelligent tools. Making AI practical.

Brok-AI is an independent open-source organization exploring practical artificial intelligence, desktop software, developer productivity, and automation.

We believe AI should be useful, approachable, and adaptable to real-world workflows.

## Our Mission

To create reliable and accessible AI-powered software, support open collaboration, and make intelligent tools more useful for developers and everyday users.

## What We Build

| Area | Focus |
| --- | --- |
| AI assistants | Desktop companions, coding assistance, and extensible AI workflows |
| Developer tools | Software that improves development and productivity |
| Automation | Practical task automation and integrations |
| Accessibility | Multilingual experiences and support for varied environments |
| Open source | Reusable software, transparent development, and community contributions |

## Featured Project

### [Brok](https://github.com/Brok-AI/Brok)

A Persian-first AI desktop companion and coding assistant, designed to bring AI-powered help and developer workflows into a desktop application.

Explore the repository for the latest roadmap, releases, documentation, and contribution opportunities.
